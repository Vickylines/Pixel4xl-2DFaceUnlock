## 减少重复推理

原模型每次输入两份相同的 112×112 RGB 图像，只使用第一份输出。新图先执行一次原有的 227 个主体算子，把得到的 512 个浮点特征复制成两行，再执行原来的两个末端卷积及 reshape。全部 138 个常量缓冲区保持逐字节一致，权重和算子参数均未修改。

保留末端的两行计算是有意的：全部改为单行时，手机上的原生内核会产生细微浮点差异。保留原末端后，136 组输入的原始向量和归一化向量全部逐位一致，最大绝对误差为 0。输入包括合成图案和公开 NASA astronaut 测试图片的亮度变体。

同一进程中交替执行新旧模型，线程数均为 2；8 次预热后记录 128 次推理：

| 模型推理 | 原图 | 新图 |
| --- | ---: | ---: |
| 中位数 | 39.895 ms | 19.277 ms |
| P95 | 41.172 ms | 19.887 ms |

推理中位数缩短 51.7%。此项为模型计算耗时，整段解锁结果见上表。逐位一致性在这台 arm64 手机上的 LiteRT 1.4.0 上完成验证。

模型空间 ID、归一化、身份阈值、双眼检查、人脸数量检查、画质检查、连续多帧规则、授权有效期和配置复查均保持原值。安装前后人脸与设置文件的 SHA-256 相同。

## 减少启动等待

删除唤醒入口固定的 80/100 ms 延时。原生回调结束后立即检查锁屏和电源状态；尚未就绪时，每 32 ms 重查，仍受原来的 1500 ms 有界窗口及会话撤销控制。所有授权和跨异步边界的用户、策略复查继续执行。

## 验证与复现

- Release 构建通过；265 项 JVM/Robolectric 检查通过。
- Release Lint：0 错误，3 条已有警告。
- 手机端 329 项检查通过，包括实际模型的形状、生命周期与输出检查。
- 136 组新旧模型输出比较通过；模型派生结果可逐字节复现。
- 8 组 40–1700 ms 亮屏后明确休眠请求全部保持息屏，相机客户端为空，SystemUI 进程稳定。
- 等待系统确认屏幕已唤醒后，分别间隔 350、900、1700 ms 触发电源键，3 组均进入 Dozing，相机客户端为空。
- 原生电源键的独立回归记录保存在本地 diagnostics。极短间隔的 POWER 切换曾由系统产生新的 power_button 唤醒；原会话当时已撤销、未启动相机宿主。明确休眠请求用于验证取消流程，POWER 切换不等同于单向休眠命令。
